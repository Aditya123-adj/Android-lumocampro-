# Lumo Camera Pro

Android CameraX starter project with photo capture, video recording, front/back camera switching, zoom presets and a dark glass-inspired interface.

## Build APK
Open **Actions** → **Build Lumo Camera Pro APK**. When the workflow completes, download the **Lumo-Camera-Pro-debug** artifact.

Camera capabilities and zoom ranges depend on device hardware. Advanced portrait processing, pose overlays, manual focus controls, timelapse and 4K selection are not included in this starter version yet.
